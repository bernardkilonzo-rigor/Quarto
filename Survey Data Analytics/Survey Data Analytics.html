Shaping Data

Show the code 
Survey_data1 <- Survey_data%>%
  pivot_longer(cols = c(q2a:q5_6), names_to = "Quiz", values_to = "Responses")%>%
  pivot_longer(cols = c(q6a:q6e), names_to = "Q6", values_to = "Values")%>%
  mutate(Quiz_group = 
           case_when(
             str_detect(Quiz, "^q2") ~ "Q2",
             str_detect(Quiz, "^q3") ~ "Q3",
             str_detect(Quiz, "^q4") ~ "Q4",
             str_detect(Quiz, "^q5") ~ "Q5",
             TRUE ~ "Others"
           ))

Show the code 
Survey_data %>%
  # Count distinct respondents per country
  count(country, respondent_s_id) %>%
  group_by(country) %>%
  summarise(Count = n_distinct(respondent_s_id)) %>%
  arrange(desc(Count)) %>%
  
  # Collapse into top 10 + Others
  mutate(country = if_else(row_number() <= 10, country, "Other Countries")) %>%
  group_by(country) %>%
  summarise(Count = sum(Count)) %>%
  arrange(desc(Count)) %>%
  
  # Add percentages using janitor
  adorn_totals("row") %>% 
  mutate(
    Percent = Count / sum(Count),
    Percent = percent(Percent, accuracy = 0.1)
  ) %>%
  
  # Rename for presentation
  rename(
    Country = country
  ) %>%
  
  # Convert to gt table
  gt()

Main Analysis

  1. Computing Customer Acquisition by Channel
Show the code 
Survey_data1%>%
        group_by(q1)%>%
        summarise(count = n_distinct(respondent_s_id))%>%
        mutate(pr = count/sum(count))%>%
        mutate(Percent = scales::percent(pr, accuracy = 0.1))%>%
        arrange(desc(count))%>%
        mutate(q1 = factor(q1, levels = q1))%>%
        ggplot(aes(y = q1, x = count))+
        geom_bar(stat = "identity", fill = "#FED789")+
        geom_text(aes(label = Percent), hjust = 1)+
        theme(
          panel.background = element_blank(),
          axis.title = element_blank(),
          axis.text = element_text(family = "serif",size = 12, color = "gray30"),
          axis.text.x = element_blank(),
          axis.ticks.x = element_blank()
        )
  1. Computing Percentage That Completed the Course.
Show the code 
Survey_data1%>%
  filter(Quiz_group == "Q2")%>%
        group_by(Quiz, Responses)%>%
        summarise(count = n_distinct(respondent_s_id))%>%
        mutate(pr = count/sum(count))%>%
        mutate(Percent = formattable::percent(pr, digits = 1))%>%
        ggplot(aes(y = Quiz, x = Percent, fill = Responses))+
        geom_bar(stat = "identity", position = "stack")+
        scale_x_continuous(labels = percent_format())+
        geom_text(aes(label = Percent), position = position_stack(vjust = 0.5),
        color = "white", size =3.5)+
        scale_fill_paletteer_d("nationalparkcolors::Acadia")+
        theme(
          panel.background = element_blank(),
          legend.position = "top",
          legend.title = element_blank(),
          axis.title.y = element_blank()
        )

Conclusion

Survey data analytics provides a powerful foundation for understanding perceptions, behaviors, and satisfaction levels across different respondent groups. By applying a structured workflow - data cleaning, descriptive summaries, Likert analysis, cross‑tabulations, and visual exploration - we transform raw survey responses into meaningful insights that support evidence‑based decision‑making.

The techniques demonstrated in this document highlight how R enables reproducible, transparent, and scalable analysis. Whether the goal is monitoring customer satisfaction, evaluating service quality, or exploring demographic trends, this workflow ensures that insights remain consistent, defensible, and easy to extend. As organizations continue to rely on data‑driven strategies, robust survey analytics becomes essential for identifying priorities, guiding interventions, and measuring impact over time.
